# Uber Data Analysis

This project contains data analysis of Uber ride data using Python and Jupyter Notebook.

## 📊 Features
- Data cleaning and preprocessing
- Visualizations (trip counts, locations, etc.)
- Insights from Uber trip data

## 📁 Files
- `DAV_Uber.ipynb`: Jupyter Notebook with full analysis

## 🚀 How to Use
1. Download the notebook.
2. Open with Jupyter Notebook or JupyterLab.
3. Run each cell to explore the analysis.

## 📎 Data Source
UberDataset.csv

## ✅ Requirements
- Python 3
- pandas, matplotlib, seaborn, numpy
